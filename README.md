# mangalens-media

Carousel images for [@mangalens.app](https://www.tiktok.com/@mangalens.app) TikTok photo posts.

`https://mangalens.app/tt/<path>` proxies to this repo (see `_redirects` in the MangaLens site), so
TikTok's Content Posting API can pull images from the verified `https://mangalens.app/` prefix.
Written by `~/.claude/skills/manhwa-tiktok/scripts/post_tiktok.py`; only the latest carousel is kept.
